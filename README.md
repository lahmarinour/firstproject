# Data Analysis Projects

This repository contains personal projects developed while learning data analysis, programming, and applied machine learning.

## Projects

### 1. StockTwits Sentiment Analysis & Market Performance
An exploratory project comparing sentiment in StockTwits messages with stock-market movements. It uses VADER and FinBERT to analyze sentiment and `yfinance` to retrieve stock prices.

[Open project folder](./projet1/)

## Tools
Python, Jupyter Notebook, pandas, matplotlib, seaborn, yfinance, NLTK, Transformers, PyTorch.

More projects and improvements will be added as I continue learning.
